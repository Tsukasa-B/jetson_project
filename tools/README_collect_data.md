1. 【メイン】ActuatorNet 学習データ収集AI（ActuatorNet）を賢くするための最重要モードです。これを一番長く回します。
```
 python3 collect_data/collect_real_data.py --mode train
```train
どんな動き？: 「ガシャガシャ、ジジジ…」手首（DF, F）とグリップ（G）が、それぞれ全く関係ないタイミングでランダムに動きます。時々「ビビビッ」という細かい振動（Chirp信号）が混ざります。目的:「手首を曲げながら握る」「反らしながら開く」といったあらゆる組み合わせパターンを網羅し、相互干渉や共収縮をAIに学習させます。目安時間: 合計 5分（1分やって休憩、を5回）2. ヒステリシス同定（モデル作成用）ゴムの特性（伸び縮みのクセ）を数式化するためのモードです。
```
 python3 collect_data/collect_real_data.py --mode hysteresis
```
どんな動き？: 「ウネウネ〜、スーッ…」3つの筋肉が、それぞれ違う周期（7秒、11秒、13秒）でゆっくり伸び縮みします。周期をズラしているため、同じ動きが二度と来ないような不思議なダンスをします。目的:「他の筋肉が引っ張っている時に、自分はどう動くか？」という**複雑なヒステリシス（相互干渉）**をきれいにスキャンします。目安時間: 2分（周期が一周してズレるまで待つため、長めに取ります）3. Sim-to-Real 比較検証（ステップ応答）シミュレーションが正しいか答え合わせするためのモードです。
```
 python3 collect_data/collect_real_data.py --mode step
```
どんな動き？: 「カクン、カクン」3秒ごとに圧力が階段状（0 $\to$ 0.3 $\to$ 0.6）に切り替わります。3つの筋肉のタイミングはズレています。目的:「指令を出してから実際に動くまでの遅れ（むだ時間）」や「行き過ぎ（オーバーシュート）」を単純な波形で確認し、シミュレータのパラメータ調整に使います。目安時間: 30秒
